# nfrnz

This is an AI inference sharing application

## rules

- use `bun` package managemer
- never edit `elm.json`, use `elm` only
- all business logic belongs inside `elm`
- use `elm-chadcn` components for UI
- use `main.ts` only for logic cannot be written in `elm`
- use `elm-ts-interop` for interop between `elm` and `ts`
- run `bun interop` to generate `elm-ts-interop` types
